Missões de Layout

Pratique conceitos essenciais de Flexbox e Grid

Hora do Jogo! Abra os desafios oficiais:

Direção e Eixo

Explore display: flex com flex-direction e conheça o eixo principal e cruzado.

Alinhamento

Brinque com justify-content e align-items para distribuir e centralizar conteúdo.

Malha Responsiva

Crie grades com display: grid, use gap e combine fr (fração), auto e minmax().

Áreas Nomeadas

Controle a página com grid-template-areas e reposicione blocos apenas com CSS.

Dimensionamento Flex

Ajuste o tamanho dos itens com flex-grow, flex-shrink e flex-basis. Ex.: flex: 1 1 200px.

Dimensionamento Grid

Faça grades fluídas com repeat() e minmax(). Ex.: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)).

Habilidades do Aventureiro

  • Flexbox: direção, wrap, espaçamento e alinhamento.
  • Grid: colunas/linhas, áreas e auto placement.
  • Responsividade: mobile-first e media queries.
  • Acessibilidade: hierarquia semântica e foco visível.
  • Boas práticas: CSS limpo, reuso e consistência.
